# Rando Itzer 3D - v3.0

Carte interactive 3D du Grand Tour de Zaghfouland & Itzer (Moyen Atlas, Maroc).

## Nouveautés v3.0 (20 Améliorations)

1. **Couches carte 2D**: Support pour couches IGN, hillshade, et préparation pour nouvelle carte.
2. **Sidebar**: Sections pliables et sidebar masquable.
3. **Chargement**: Barre de progression et message de bienvenue.
4. **Ciel nocturne**: Lune 3D, lumière directionnelle, brume.
5. **Sons ambiants**: Sons adaptatifs (heure) et contrôle volume.
6. **Mobile**: Bottom nav, bouton FAB, responsive complet.
7. **POI interactifs**: Tooltip au survol 3D.
8. **Style UI**: Glassmorphism et dark neumorphism amélioré.
9. **Mini-carte**: Indicateur caméra et redimensionnable.
10. **Graphique altitude**: Curseur 3D synchronisé et zones colorées.
11. **Raccourcis clavier**: Ajout raccourcis pour les boucles (Q, W, E, R, U).
12. **Capture**: Support pour JPEG HD et GIF animé.
13. **HUD marcheur**: Statistiques (pas, calories, distance restante).
14. **Marqueurs animés**: Feu de bivouac la nuit et reflets sur l'eau.
15. **Partage social**: Boutons WhatsApp, Twitter, Instagram.
16. **Météo**: Widget avec icône animée sur la carte.
17. **À propos**: Fenêtre modale avec statistiques et crédits.
18. **Transitions**: Effets de fondu au changement de moteur de rendu.
19. **Recherche**: Mise en évidence des résultats.
20. **Déploiement**: Déploiement GitHub Actions -> Vercel (Auto-déploiement).

## Développement

Lancer le serveur de test :
```bash
python -m http.server 8000
```

Lancer les tests :
```bash
python test_suite.py
```
